# 📚 CTeca — Biblioteca Virtual Escolar

O **CTeca** é uma plataforma de catálogo digital desenvolvida para otimizar a consulta e a gestão do acervo físico da biblioteca escolar. O objetivo do projeto é permitir que os estudantes pesquisem previamente as obras disponíveis, verifiquem a localização dos exemplares nas estantes e acompanhem o status de empréstimo antes de se deslocarem até a biblioteca presencial.

---

## 🎯 Objetivo do Projeto

* **Transparência:** Facilitar a busca de títulos literários e didáticos existentes na escola.
* **Agilidade:** Permitir a checagem rápida de disponibilidade de exemplares em tempo real.
* **Incentivo à Leitura:** Tornar o acervo físico mais acessível e visível para toda a comunidade escolar.

---

## 👤 Público-Alvo (Personas)

* **Alunos da Escola:** Estudantes que precisam consultar a existência de livros para pesquisas acadêmicas ou leitura de lazer, verificar se determinado título está disponível para retirada presencial e planejar suas visitas à biblioteca.

---

## 🏷️ Tipo de Projeto

* **B2C (*Business-to-Consumer*) / *Institution-to-Student*:** Modelo focado no atendimento direto da instituição de ensino (provedora do serviço) para seus alunos (usuários finais).
